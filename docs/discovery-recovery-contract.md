# Discovery recovery contract

The server workspace snapshot owns all eleven journey steps. Parsed active evidence enables Free Diagnosis; a current completed report enables Review Findings; a verified review enables Full Diagnosis. Payment applies only to the deeper Full Diagnosis included in the first paid engagement, scoped to its actual project and verified plan. Earlier company-wide legacy entitlements do not unlock unrelated projects.

Generation requests have durable request keys and a unique running attempt per engagement. A prompt background kick reuses leased stage processing and the existing two-minute worker. Refresh reads state only. Regenerate preserves history. Three interrupted claims terminate a stuck attempt while keeping uploaded evidence and completed chunks.

Canonical document scope includes discovery material and client submissions in the exact context, plus explicitly linked source discovery after payment. Removed evidence stays historical. Identical normalized content contributes one logical source, with both original files retained. Free reports use the versioned parsed evidence ledger. Coverage and Full Diagnosis additionally include completed client answers and labeled admin context; these contextual sources are intentionally distinct from uploaded document counts.

Gateway balance, configuration, provider response, model output, schema, database, authorization and local deadline errors have distinct codes. Full response-body reading is inside the deadline boundary. A local application abort is APPLICATION_TIMEOUT; an upstream 504 is MODEL_TIMEOUT. Client messages omit raw provider details. Correlation metadata contains no transcript or credentials.

Quality review returns bounded corrections and validates the entire resulting report, avoiding a second full report rewrite. Existing model deadlines are unchanged. Production acceptance must use real retained evidence and a real model response; deterministic fixture results do not establish live acceptance.
