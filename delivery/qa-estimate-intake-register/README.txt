QA ESTIMATE INTAKE REGISTER — HANDOFF GUIDE
Version 1, 7 September 2026. Synthetic QA only.

WHAT YOU RECEIVE
A self-contained offline HTML register, with its tutorial and FAQ embedded.
Open the preview and choose Download offline tool. Save the HTML file and open it in a browser. Keep the exported JSON backup separately.

USE
1. Add a unique request ID, site, contact, owner role and requested scope.
2. Select urgency and status yourself. Add a due date and source if available.
3. Save and check the saved record. Use Edit request to update it.
4. Export JSON after each work session. CSV is for spreadsheet review.
5. To restore, select a JSON backup, review the record count, then confirm replacement. Cancel leaves the current register unchanged.

DATA AND PERMISSIONS
Only browser localStorage is used. No data synchronization, remote database, external messages, pricing or quote generation occurs. Owner role is a descriptive label, not access control. Use synthetic information only. Incognito sessions and cleared browser data can remove records. Hosted and downloaded copies may have separate storage; transfer with JSON.

RECOVERY
Keep dated JSON backups outside the browser. Export the current register before restoring an older backup. Invalid imports are rejected before saving. A storage failure is visible and does not report success. Do not edit JSON structure by hand.
