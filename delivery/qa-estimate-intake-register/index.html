Tutorial and FAQ

How to use the register
  1. Enter a unique request ID and the required site, contact, owner role and scope.
  2. Select urgency and status yourself. Add a due date and a source if available.
  3. Choose Save request. Check the saved card and success message.
  4. Use Edit request to update a record. The ID stays fixed while editing.
  5. Export JSON after each work session. To move browsers, open this tool there and restore that backup.
Where is my data stored?

Only in localStorage for this browser and this page’s origin. No records are sent to Relystra or any integration. Incognito data disappears when its session closes. Hosted and downloaded copies may use different storage; transfer data with JSON.

What does this tool automate?

Required-field checks, duplicate detection, local saving and file export. It does not choose owners, determine urgency, estimate prices, issue quotes or send messages. Owner roles are descriptive labels, not permission controls.

How do I recover or roll back?

Keep dated JSON backups outside the browser. Choose the prior backup under Restore, review the confirmation count, and confirm replacement. Export your current records first. Invalid files are rejected without changing saved records.

Why did a save or import fail?

Read the visible message. Check required fields, unique IDs, allowed statuses and valid dates. Imports must be an unmodified JSON backup from this tool. If storage is unavailable or full, export current data, then retry in a normal browser. A failed save never reports success.

What is outside this QA Build?

Production customer data, multiuser synchronization, access control, CRM or accounting integrations, automated pricing and customer messaging. No real Blue Harbor operational performance is asserted. Additional workflows need separately approved scope.
